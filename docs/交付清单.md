## 二、快速开始

1. **安装桌面端**：到 GitHub Releases 下载最新 `*-setup.exe`（SmartScreen 若提示，点"仍要运行"）。装完即可使用；此后新版本会自动检查更新。
2. **查看原型**：直接双击 prototypes 下两个 HTML 文件。
3. **跑小程序**：微信开发者工具导入 `简记小程序/`，AppID 已填好，编译即用。
4. **看源码/参与开发**：克隆仓库 `git clone https://github.com/YU06118/jianji.git`，见 docs/GitHub上传流程.md 与 docs/API.md。
