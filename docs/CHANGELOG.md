# 更新日志

> 格式参考 Keep a Changelog。桌面端版本以 `desktop/package.json`、`tauri.conf.json`、`Cargo.toml` 三处一致为准。

## 桌面端（Tauri v2）

### v0.1.8 — 2026-11-19

- **分类管理增改删（原"点击编辑"无反应）**：根因是功能从未实现（卡片无事件、编辑弹窗缺失、后端命令未接线），本版完整补齐。
  - 新增 `#cat-modal` 编辑/新建复用弹窗：可改名称、emoji 图标（20 选 1）、颜色（10 选 1）、收支类型；卡片点击走事件委托（innerHTML 重渲染不丢事件）。
  - 接入 `list_categories`/`save_category`/`delete_category` 三命令；预设分类可编辑不可删，自定义分类可删（后端 `custom=1` 约束）。
  - 修复「＋新建」内联 `toast(...)` 的 ReferenceError 死链。
- **每日记账提醒可自定义时间**：原开关与「21:00」均为纯装饰。
  - 设置页新增 `<input type="time">`（时分精确到分钟）+ 开关，写入 `remind_daily_enabled`/`remind_daily_time`（默认开 / 21:00）。
  - Rust 侧新增 `tauri-plugin-notification` + 独立轮询线程（每 15s），到点弹系统通知，`remind_daily_last_fired` 保证当日只发一次。**仅应用运行时提醒**，关闭应用不提醒。
- **统计大数字改真实数据**：原 ¥86,420/¥41,208/¥45,212 是 HTML 写死的假数据，与明细/图表不同源。现三卡按当前时间维度（周/月/年/近3年/近5年）从真实记录计算收入/支出/结余/月均，与下方图表同口径；补「周」维度过滤；空数据显示 ¥0.00。
- **明细金额可修改/删除**：「记一笔」弹窗改为新增/编辑双模式，可改金额/备注/日期/分类/类型/小票图片；编辑保留原 id 与时间戳（`save_record` 本身是 upsert，不产生重复记录）。删除改自绘确认框，走软删。
- **回收站打通**：原「回收站」是摆设。现可切换回收站视图、逐条恢复（`trash_record` deleted=0）、清空（`purge_trash`）；修复明细列表曾混入已删除记录的瑕疵。
- **WebView2 弹窗加固**：搜索的原生 `prompt()` 改为自绘输入框；导出数据死链改为正常绑定。所有确认/输入交互不再依赖原生弹窗。

### v0.1.7 — 2026-11-19

- **记账输入原生化**：移除「记一笔」弹窗的自定义数字键盘，改用原生 `<input type="text" inputmode="decimal" maxlength="8">`，由系统/物理键盘输入金额。
  - 新增 `sanitizeAmt()` 纯函数承接原键盘规则（仅数字与单个小数点、前导零折叠、8 字符上限、多小数点与非法字符纠正）。
  - 金额单一数据源改为 `#amt.value`；打开弹窗自动聚焦并全选，回车或「完成」按钮均可提交；「小票」按钮保留拍照能力。
  - 拍照 / 完成按钮重新安置到弹窗底部操作行。
- **深色档整窗渐变**：桌面端窗口背景对齐小程序端 `linear-gradient(180deg,#2E2745 0%,#202020 100%)`；新增 `--win-bg` token，深色档主区透明以露出渐变，玻璃浮层质感保留。浅色档跟随系统且完全不变。

## 微信小程序端

### v1.0.0 · 视觉 4.0 — 2026-11-18

**配置**
- 填入真实 AppID `wx7e44ad0c1a857e87`（替换 `touristappid`），编译通过。

**外观系统（Fluent 2）**
- 全局视觉重写：四套主题色、明暗双档 token、线性 SVG 图标 20 枚（`assets/icons/`），移动端适配。
- 暗色设为默认，保留浅色/跟随系统两档；新增独立**设置页** `pages/settings/`，「我的」页收敛为概览 + 设置入口。
- WCAG 对比度治理：重算相对亮度，修正 `--ink-3` 等不达标值，四套强调色的白字组合全部达标（≥4.5:1）。
- 引入双强调色分工：`--pink` 作前景、`--accent-solid` 作背景，解决深色底上白字对比不足。
- 技术要点：WXSS `prefers-color-scheme` 无法被 JS 覆盖 → 根节点 `.mode-dark/.mode-light` 全量重声明 token；`theme.json` 双主题 + `darkmode: true` 让原生导航栏 / tabBar 跟随；`wx.setNavigationBarColor` 仅当前页生效，配合 `app.js` 的 `syncAppearance` 做导航 + tabBar + 窗口底色三件套兜底。

**导航与背景**
- 导航栏统一为深紫黑 `#1E1A2E`（此前首页蓝、记账页白不一致），浅色档同样白字（对比度 16.90:1）。
- 深色 / 跟随系统深色时，页面背景改为低调暗紫渐变 `#2E2745 → #202020`；浅色档保持浅底。

**记账体验**
- 移除自定义数字键盘（整目录 `components/numpad/` 删除），金额输入改用系统输入法 `type="digit"` + `confirm-type="done"`。
- 新增 `sanitizeAmount()`：逐字符重放原 `appendAmount()` 逻辑，保持输入语义 100% 一致；回车与按钮双保存入口用 `_submitting` 标志防重复写入。

**统计**
- 修复环形图边缘裁切：按环厚反解半径 `r = (min(w,h)/2 - margin) / (1 + ringRatio/2)`，保持画布 300rpx 不变、环厚调细。
