# 小程序 → Windows 桌面端 移植改动对照表

> 移植基线：`YU06118/jianji-miniprogram` `main` 分支（d42661c..264ede1，共 19 个提交）

> 日期：2026-11-22

## 一、架构决策

| 项 | 决策 | 理由 |
|---|---|---|
| 运行框架 | **保留 Tauri v2**（未换 Electron） | 现有 Rust 后端（db.rs SQLite + 17 个 invoke 命令）可直接复用；安装包 5-10MB vs Electron 150MB+；无 Electron 独占能力需求 |
| UI 策略 | **按小程序 Apple 卡片体系 v5 1:1 移植** | 用户确认「UI 按照小程序的来」 |
| 内容列宽 | 750rpx → `--rpx: 0.6px`（450px 居中） | rpx 换算统一走 CSS 变量 |
