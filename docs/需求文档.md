# 简记 · 需求文档 v1.0

> 经 30 轮 + 4 补充轮互动式调研确认。轻奢简洁（Apple HIG 风格）的个人记账程序，双端交付。

## 1. 项目定位
- **产品名称**：简记
- **目标**：个人日常记账、极简自用；弱化协作、多账户、复杂预算
- **货币**：人民币 ¥，两位小数（精确到分）
- **工期**：质量优先、分阶段（原型 → 功能 → 打磨）

## 2. 功能需求

### 2.1 收支记录（增删改查）
- 字段：金额 / 分类 / 日期 / 收支类型 / 备注文字 / 图片小票（不设标签）
- 录入：手动数字键盘 + 拍照/选小票；不做语音、不做账单文件导入
- 检索：备注关键词 + 分类/收支 + 日期月份 + 金额区间（四类全支持）
- 删除：进回收站可恢复

### 2.2 分类管理
- 内置预设分类 + 自定义增删改；单层分类，不做二级

### 2.3 统计汇总
- 时间维度：周 / 月 / 年 / 近 3 年 / 近 5 年
- 图表：分类占比环形/饼图 + 收支趋势折线/面积图 + 分类对比柱状图 + 日历热力图
- 导出：PDF 报表 + Excel/CSV + JSON 备份

### 2.4 预算与周期
- 不做预算；不做多账户与转账（资金来源写备注）
- 周期收支：到期提醒、手动补记，不自动生成

### 2.5 提醒与隐私
- 每日记账 + 月度账单 + 周期到期提醒；不做超支异常提醒
- 不设密码锁，打开即看；不做应用内隐藏金额

## 3. 界面设计（Apple HIG）
- 视觉基调：冷调极简黑白灰 + 少量强调色（靛蓝 #4F5BD5）
- 毛玻璃：导航栏 / 弹窗浮层 / 统计卡片；内容流水区纯色
- 排版：大标题 + 字号层级、充足留白、等宽表格数字、讲究中文字体
- 动画：精致弹性微交互 + 流畅页面转场为主，关键反馈点做辨识度，其余克制
- 桌面布局：左侧栏导航 + 主内容区；小程序 TabBar：首页/记账/统计/我的
- 无障碍：深浅色、减弱动态、增强对比的 media query

## 4. 数据存储
- Windows：本机 SQLite 文件 + 图片本地目录
- 小程序：本地存储 + 微信云开发（关键数据上云支持换设备恢复）
- 双端打通：自动云同步（主）+ JSON 备份导入导出（兜底）+ 扫码迁移（便捷）
- 云端认证：同步码/口令（云端生成码，两端填同一码关联，无账号体系）
- 备份容错：手动导出 + 自动定时备份（可回滚）+ 回收站

## 5. 技术选型
- Windows exe：Tauri v2（Rust 内核 + 系统 WebView，小体积、连 SQLite）
- 小程序：基于 family-ledger-miniprogram 模板定制（页面 6→4，叠加云开发与 Apple HIG 视觉）
- 代码复用：共享数据格式 + 核心记账/统计逻辑；界面层两端各自原生
- 前置事实：三个既有技能均不直接产出 exe，Tauri 封装为新增工作量
