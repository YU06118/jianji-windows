# 简记 · 使用与部署说明

## 一、Windows 桌面端（exe）

### 1.1 运行
- 双击 `简记.exe` 即可运行（数据存本机）。
- 数据文件位置：应用会自动在 `%APPDATA%\com.jianji.ledger\` 下创建：
  - `jianji.db`：SQLite 数据库（收支记录、分类、设置）
  - `images\`：小票图片目录

### 1.2 功能
- **概览**：本月收入/支出/结余卡片、收支趋势、支出分类环形图、最近记录
- **明细**：全部流水、按日期分组、删除进回收站、关键词/类型/金额筛选
- **统计**：周/月/年/近3年/近5年切换、分类柱状图、日历热力图
- **分类**：预设 + 自定义分类
- **设置**：主题、每日记账提醒（可自定义时分，如 08:30；默认 21:00，仅应用运行时提醒）、自动检查更新、CSV 导出
- **记一笔**：数字键盘、收支切换、分类、备注、小票图片

### 1.3 从源码构建
前置条件：Rust（rustup）、Node.js 18+、VS Build Tools（C++ 桌面负载）、WebView2 运行时。
```bash
cd desktop
npm install
npx tauri build
```
产物：`desktop/src-tauri/target/release/bundle/` 下的 `.msi` 与 `.exe`（NSIS）。

> 本机（i7-12700H + Defender 实时保护）release 全量优化曾出现单 crate 编译挂起；
> 若遇到，可先 `npx tauri build --debug`（产物在 `target/debug/`，可直接运行），
> 或将项目目录加入 Defender 排除列表后再做 release。

## 二、微信小程序端

### 2.1 本地预览（无需账号）
1. 双击 `简记小程序/预览版.html`，在浏览器中体验完整记账流程。

### 2.2 导入微信开发者工具
1. 打开微信开发者工具 → 导入项目
2. 目录选择 `简记小程序/`（能看到 app.json 那一层）
3. AppID 已配置为 **`wx7e44ad0c1a857e87`**（`project.config.json`），无需再改；要临时体验也可选「测试号」
4. 编译后即可体验；数据在小程序本地存储
5. 「我的」→「填一份示例数据」可生成 26 笔本月示例账 + 预算 + 攒钱目标
6. 外观在「我的」→「设置」中切换：暗色（默认）/ 浅色 / 跟随系统，另有四套主题色

### 2.3 AppID 与云开发（账号已完成注册）
> 本项目 AppID 已配置并编译通过。以下为换号 / 重新配置时的参考流程。

1. 访问 mp.weixin.qq.com → 登录已有账号 →「开发」→「开发管理」→「开发设置」复制 **AppID**
2. 在微信开发者工具项目设置中填入新 AppID（同步更新 `project.config.json`）
3. 如需云同步：开发者工具点「云开发」→ 开通环境（部分套餐有免费额度，超出按量计费）；不开通也能用本地数据与 JSON 备份
4. 外观相关：`theme.json` 已声明双主题，原生导航栏统一深紫黑 `#1E1A2E`；勿手改成浅色，否则深浅档会不一致

### 2.4 上线前必做
- mp 后台填写《用户隐私保护指引》，勾选「剪贴板」接口（备份/恢复依赖它）
- 类目选择：工具 → 实用工具 → 记账
- 名称/简介/截图不得出现「理财」「投资」等金融词汇
- 提审前运行安全体检：`node tools/security-audit.js`

## 三、双端数据同步
- **自动云同步（主）**：依赖微信云开发，设置中填同一「同步码」关联两端
- **JSON 备份（兜底）**：桌面端设置中导出 JSON；小程序「我的」→备份恢复导入
- **扫码迁移（便捷）**：换机时一端生成码，另一端扫描导入
- 说明：云端同步功能需先完成 2.3 的云开发环境开通；未开通前可用 JSON 备份在两端迁移。

## 四、自检命令
```bash
# 共享核心逻辑（26 项）
node shared/core.test.js

# 小程序数据层（88 项）
cd 简记小程序 && node tools/selfcheck_data.js .

# 小程序 UI 层（118 项，需 jsdom）
NODE_PATH=<node_modules路径> node tools/selfcheck_ui.js .

# 小程序安全体检
node tools/security-audit.js
```
